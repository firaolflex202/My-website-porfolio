About

I want to know how the work is made, then put it into ordinary life.

I’m Firaol Dereje Tsegaye, currently learning full-stack web development. The interesting part, for me, is not a stack for its own sake — it is the framework of how code is built, and how that same thinking can move through the rest of a day: tools, collaboration, small useful things.

This site is a first public piece: a still pool that only moves when you do. Click the water and the surface lifts. I’m looking for people to learn with, and projects that need a careful pair of hands.
